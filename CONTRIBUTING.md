# Contributing

- Do not add commercial game files, keystores, or SDK tarballs.  
- Do not return a successful Android build without a real artifact.  
- Prefer another evidence layer over a higher magic number on one filename.  
- Keep adapters honest when the tool is missing.  
- Run `pytest -q` before submitting.  
- Update `CHANGELOG.md` and `SUPPORTED_ENGINES.md` when detection changes.
